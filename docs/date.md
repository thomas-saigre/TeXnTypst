# Date and time


We could also use the package [`datetime`](https://ctan.org/pkg/datetime).
```tex
\date{23/11/1994}
```

Date and time are handled with [`datetime`](https://typst.app/docs/reference/foundations/datetime/).

```typ
datetime(
    year: 1994,
    month: 11,
    day: 23
),
```
